# Countdown Ticker

Countdown Ticker is an Expo + React Native demo that shows a large, animated number ticker. Each digit spins smoothly into view when the value changes, making it great for countdowns, scoreboards, or any screen that needs eye-catching numbers.

## Features
- Animated digit columns powered by [moti](https://moti.fyi/)
- Button-driven updates that demonstrate stateful ticker changes
- Simple layout you can drop into any Expo Router tab
- Works on iOS, Android, and the web via Expo

## Getting Started
1. Install dependencies
   ```bash
   npm install
   ```
2. Start the dev server
   ```bash
   npx expo start
   ```
3. Follow the Expo CLI prompts to open the project in Expo Go, an emulator, or the web browser.

Use the button on the home tab to trigger new numbers and watch the digits slide into place.

## Project Structure
- `app/(tabs)/ticker.tsx` – Ticker component with animation and state
- `app/(tabs)/home.tsx` – Renders the ticker and user control
- `assets/` – Icons and splash assets generated by Expo
- `metro.config.js` – Metro bundler configuration for Expo

Feel free to fork the repo and customize the ticker for your own countdowns or dashboards!
